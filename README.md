# Creator-AI

Creator-AI is an advanced AI bot and engine platform. It provides an interface to chat with the Creator model and features an extensible architecture.

## Features
- Interactive AI chat interface
- Extensible Creator model engine
- Integration with FreeLLM and custom API gateways
- Easy-to-use web UI

## Getting Started
1. Run the local backend server (e.g. `python creator_model/model_server.py`)
2. Open `index.html` in your browser or run a local HTTP server to view the interface.
